# Task Manager — PyQt6

## Опис проєкту

Task Manager — це графічний застосунок для створення та керування списком завдань, розроблений мовою Python із використанням бібліотеки PyQt6.

## Можливості програми

- Додавання нових завдань.
- Редагування та видалення завдань.
- Позначення завдань як виконаних.
- Вибір категорії та пріоритету.
- Відображення статистики завдань.
- Перевірка правильності введених даних.
- Експорт завдань у формат JSON.
- Використання стандартних і власних діалогових вікон.
- Адаптивний графічний інтерфейс.

## Вимоги

- Python 3.14 або сумісна версія.
- PyQt6.

## Встановлення

Встановіть залежності командою:

```bash
pip install -r requirements.txt
```

## Запуск програми

Виконайте команду:

```bash
python main.py
```
